# 森林火災シミュレーション (C3/water_Fire)

標高、風、植生密度の影響を組み込んだセル・オートマトンベースの森林火災シミュレーションです。消火活動のためのインタラクティブな水撒き機能をサポートしており、複数の地形モード（ダミー、CSV、API）で動作します。

## ディレクトリ構成

- `ForestFire_Auto_numba.py`: Numbaで高速化されたメインのインタラクティブ・シミュレーションスクリプト。
- `ForestFire_Auto_anim.py`: シミュレーションのGIFアニメーションを生成するためのスクリプト。
- `update_grid_numba.py`: Numbaで最適化されたシミュレーションのコアロジック（セル・オートマトンのルール）。
- `config.py`: シミュレーションパラメータを一元管理する設定ファイル。
- `param.txt`: 物理パラメータの参照用ファイル。
- `cells.py`, `gsi_fetcher.py`: セル定義や国土地理院標高API用のヘルパーモジュール。
- `USA_Fire/`: 地形や着火点のCSVデータを含むディレクトリ。

## 設定

すべてのシミュレーションパラメータは `config.py` で管理されています。以下の設定を調整できます：

- **シミュレーション**: `GRID_SIZE`（グリッドサイズ）, `CELL_SIZE_M`（セルサイズ）, `RECOVERY_TIME`（回復時間）
- **物理**: `P_H`（燃焼確率）, `SLOPE_FACTOR`（傾斜係数）, `WIND_SPEED`（風速）, `THETA_W`（風向）
- **係数**: `C_1`, `C_2`（風の影響係数）
- **水との相互作用**: `ACTIVE_THRESHOLD`（水撒き有効化の閾値）, `WATER_ON_ACTIVE_DURATION`（水の持続時間）など
- **ファイルパス**: 標高、植生、着火点データのCSVファイルパス。

### パラメータの変更方法
テキストエディタで `config.py` を開き、値を変更してください。変更は次回のスクリプト実行時に適用されます。

## シミュレーションの実行

### インタラクティブモード
メインスクリプトを実行して、インタラクティブなシミュレーションウィンドウを起動します：
```bash
python ForestFire_Auto_numba.py
```
- **一時停止/再開**: "Pause" ボタンをクリックします。
- **水撒き**: 火災が十分に拡大すると（`ACTIVE_THRESHOLD`）、"Water" ボタンが有効になります。クリックして水撒きモードを有効にし、マップ上をドラッグして水を撒きます。

### アニメーションモード
シミュレーションのGIFを生成するには：
1. `config.py` を開きます（アニメーション固有の設定が必要な場合は `ForestFire_Auto_anim.py` を直接編集）。
2. 以下を実行します：
```bash
python ForestFire_Auto_anim.py
```
インタラクティブモードとGIF保存モードを切り替えるには、`ForestFire_Auto_anim.py` のソースコード内の `EXPORT_GIF` フラグを確認してください。
